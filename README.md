# Quick Commerce Analytics Platform

## Project Overview

A complete business intelligence solution for quick-commerce operations in Coimbatore. This project simulates a dark-store based delivery network similar to Blinkit, Zepto, and Instamart using MySQL and Power BI.

The platform enables monitoring of:

- Revenue and Orders
- Delivery Performance
- Customer Satisfaction
- Inventory Health
- Store Performance
- Operational KPIs

## Dashboards

### Executive Dashboard

Provides:

- Total Revenue
- Total Orders
- Average Order Value
- Customer Rating
- Revenue by Store
- Orders by Area
- Delivery Status Distribution

### Delivery Operations Dashboard

Provides:

- Average Delivery Time
- Total Deliveries
- Average Distance
- Active Delivery Partners
- Partner Performance
- Area Performance
- Delivery Status Analysis

### Inventory Intelligence Dashboard

Provides:

- Total Products
- Average Stock Available
- Critical Stock Items
- Inventory Health Distribution
- Inventory by Store
- Reorder Risk Analysis
